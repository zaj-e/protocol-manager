## Format and meaning

- `active`: the user reports currently doing or using it.
- `paused`: temporarily suspended, with the reason or restart condition if known.
- `stopped`: no longer part of the current routine; retain its ID and decision history.
- `unknown`: there is an item to record, but current use is not established.

Use stable IDs such as `P001`, `P002`, and so on. Never reuse an ID. Areas are ordinary labels such as skin, hair, oral health, exercise, sleep, or nutrition; extend them when needed.

Keep status and frequency in the Practices table only. Put supplemental context in the corresponding item detail section. A candidate that is merely being considered belongs in a decision record, not in this table. Owning a product alone does not establish active use.

This file describes the routine and context; it does not imply completion on any particular day. Dates and measurements are included only when supplied or actually observed. Research findings and their sources belong in [decision records](../decisions/README.md).
